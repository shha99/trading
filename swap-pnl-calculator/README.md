# 장외파생 스왑 손익 계산기

설치나 서버 없이 `index.html` 하나만 브라우저로 열면 동작하는 정적 페이지입니다(외부 라이브러리 없음).

| 탭 | 계산 내용 |
|---|---|
| 금리스왑 IRS | 고정/변동 레그 PV, Dirty/Clean MTM, 경과이자, 시장 등가 고정금리, DV01, 금리 평행이동 시나리오, 잔존 현금흐름 |
| 통화스왑 CRS | 원화/외화 레그 PV(원금교환 포함), 원화환산 MTM, FX 델타, 통화별 DV01, 환율 시나리오 |
| FX 스왑 | 근일물/원일물 레그 평가(금리평형 또는 시장 스왑포인트), 현물·스왑포인트 민감도 |
| TRS / 주식스왑 | 가격손익 + 배당 − 펀딩비용, 손익분기 가격, 델타, 가격 시나리오 |
| CDS | 시장 스프레드로 평탄 부도강도 보정 → Clean/Dirty MTM, Upfront, RPV01, CS01, JTD |
| 상품스왑 | 결제 완료 기간 실현손익 + 미결제 기간 선도 MTM, 가격 민감도 |

IRS·CRS·FX스왑·CDS 탭에서 직전 평가금액과 기간 중 순현금흐름을 입력하면
**기간 손익 = ΔMTM + 실현 현금흐름**으로 나눠 보여줍니다.

## 커브 입력 형식

```
3M 2.55
1Y 2.56
5Y 2.78
```

제로금리(%)이며, 기간 사이 값은 선형보간하고 할인은 연속복리로 합니다. 기본으로 들어 있는 값은 예시입니다.
