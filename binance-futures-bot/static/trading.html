⚙️ 실계좌 자동매매를 직접 켜려면

이 화면 자체는 어떤 값도 바꾸지 않는다 — 순수 조회용이다. 실제로 켜려면 Render(또는 배포 중인 곳) 대시보드의 Environment 화면에서 아래 값을 직접 설정해야 한다(API 키는 여기 어디에도 입력/저장하지 않는다).

키값
BINANCE_API_KEY / BINANCE_API_SECRET본인 바이낸스 선물 API 키 (출금 권한은 반드시 끌 것)
BINANCE_TESTNET테스트넷 먼저 true, 검증 후 실계좌는 false
WICK_AUTO_TRADE_ENABLEDtrue (볼린저 꼬리터치+RSI 켜기)
WICK_AUTO_TRADE_WHITELIST예: BTCUSDT:15m (쉼표로 여러 개)
AUTO_TRADE_ENABLED / AUTO_TRADE_WHITELIST켈트너 전략 켜기(별개 스위치) - 예: BTCUSDT:1h
RISK_PER_TRADE_USDT / LEVERAGE / MAX_OPEN_POSITIONS / DAILY_LOSS_LIMIT_USDT계좌 규모에 맞게 조정
  • 반드시 테스트넷으로 먼저 며칠 검증한 뒤에만 실계좌로 전환할 것.
  • 처음엔 조합 1개, 작은 금액으로 시작할 것.
  • 자세한 설명·위험 고지는 저장소 README "실계좌 자동매매" 섹션 참고.
